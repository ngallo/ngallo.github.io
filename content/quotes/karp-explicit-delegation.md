> If Agent A is not authorized to delegate payment authority to Agent B, then Agent A can either share its credentials with Agent B (impersonation) or proxy requests from Agent B (Agent A does whatever Agent B tells it to do). In either case, you've lost the fact that Agent B decided what action got taken. Allowing an explicit delegation of a subset of Agent A's permissions to Agent B provides the audit trail you need for governance.
